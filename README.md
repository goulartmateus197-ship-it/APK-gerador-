# Detector Visual FF — protótipo Android

Protótipo inicial em Kotlin para Android. A primeira etapa permite selecionar um vídeo gravado da partida.

## Abrir
1. Extraia o ZIP.
2. Abra a pasta `DetectorVisualFF` no Android Studio.
3. Aguarde a sincronização do Gradle.
4. Execute em um aparelho Android ou emulador.

## Escopo desta versão
- Base de aplicativo Android.
- Seletor de vídeo local.
- Estrutura preparada para evoluir para análise de quadros gravados.

Não inclui overlay/ESP durante partidas, leitura da memória do jogo ou detecção de inimigos ocultos. A seleção do vídeo ainda não executa reconhecimento automático; isso é uma próxima etapa de desenvolvimento.
